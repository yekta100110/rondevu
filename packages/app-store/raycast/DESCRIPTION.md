Quickly share your [rOndevu](https://rondevu.org) meeting links with Raycast. Requires [Raycast.com](https://www.raycast.com/) to be installed and the [rOndevu](https://rondevu.org) from the Raycast Store needs to be installed: https://www.raycast.com/cal/. You can create an API token in your Developer [rOndevu](https://rondevu.org) Settings, and then you can add the API Key by opening up the [rOndevu](https://rondevu.org) App in Raycast.

# Product Context — rOndevu

## Why This Project Exists
rOndevu is a self-hosted, open-source scheduling platform that gives individuals full control over their appointment/meeting scheduling without depending on commercial SaaS platforms like Calendly or Cal.com's paid tier.

## Problems It Solves
- **Privacy**: Users own their data — no third-party SaaS has access
- **Cost**: Free and open-source, no subscription fees
- **Customization**: Full source code access for modifications
- **Independence**: No license key or commercial account required

## How It Should Work
1. User sets up their availability schedule
2. Creates event types (30-min meeting, 1-hour consultation, etc.)
3. Shares booking link with clients/contacts
4. Clients select available time slots and book
5. Both parties receive confirmation emails
6. Calendar sync keeps everything in sync (Google Calendar, etc.)
7. Video conferencing automatically created (Daily.co)

## User Experience Goals
- Simple, clean booking experience for both hosts and guests
- Easy self-hosting setup
- Seamless calendar integration
- Multi-language support for global users
- Embeddable widgets for websites

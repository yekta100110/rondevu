# Project Brief — rOndevu

## Overview
rOndevu is a self-hosted scheduling/appointment platform built as a fork of Cal.diy (the open-source community edition of Cal.com). All enterprise/commercial features have been removed; the project is 100% MIT-licensed.

## Core Requirements
- Open-source, self-hosted scheduling platform
- Individual user focused (no teams/organizations/enterprise features)
- Calendar integration support (Google Calendar, etc.)
- Video conferencing support (Daily.co)
- Embeddable booking widgets
- Multi-language support (i18n)
- REST API (v2) and tRPC API

## Goals
- Provide a fully open-source alternative to Cal.com
- Enable self-hosting for individuals who want control over their scheduling
- Maintain clean, type-safe codebase

## Project Status

- Build configuration adjusted (TypeScript/ESLint errors currently ignored)
